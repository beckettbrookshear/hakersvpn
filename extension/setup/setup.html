Set up your HakersVPN server

Three steps, all in your browser. You'll rent a small server (about $4–6/month), and this page handles the rest.

1 Copy your setup script

This creates a private password for your server and puts it in the script. The extension remembers it, so you never have to type it.

Using your own domain? (optional)

Point it at your server's IP first. Leave blank to use a free automatic address.

Copied ✓

2 Create a server and paste the script

Sign up with any of these providers, create a new server, and choose Ubuntu 24.04 with the smallest size. Pick a location in the country you want to appear to browse from.

ProviderWhere to paste the script
DigitalOceanCreate Droplet → Advanced options → Add initialization scripts
HetznerCreate Server → Cloud config
VultrDeploy → Additional features → Cloud-Init User-Data

If the provider has a separate firewall, allow incoming ports 80 and 443.

3 Enter your server's IP address

Once the server is created, copy its IPv4 address from the provider's dashboard.
