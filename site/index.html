HakersVPN

A browser VPN for Chrome, Edge and Brave. It sends your browser's traffic through your own server.

Download the extension (.zip)

Built from the latest code on GitHub · Source code

Install on this computer

  1. Download the .zip above and unzip it. Keep the unzipped folder somewhere permanent, because the browser loads the extension from it.
  2. Open chrome://extensions (or edge://extensions, brave://extensions).
  3. Turn on Developer mode.
  4. Click Load unpacked and choose the unzipped hakersvpn-extension folder.
  5. Click the HakersVPN icon, enter your server details, then click Connect.

You also need a server

The extension connects to a small proxy server that you run on a VPS. To set one up, follow the instructions in the README.

This only covers browser traffic. Other apps on your computer still connect directly.

Updating

Download the .zip again, replace the contents of the folder, then click the reload icon on the extension's card in chrome://extensions.
